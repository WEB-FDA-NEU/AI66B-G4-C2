Editing help

How to edit a post

Editing is for clarifying meaning, not changing it. Keep the original author's intent intact.

  • Fix typos & grammar — small edits that don't change meaning.
  • Add missing context — versions, error messages, repro steps.
  • Improve formatting — fenced code blocks, tags, headings.
  • Don't answer in the question body. Use a separate answer.
