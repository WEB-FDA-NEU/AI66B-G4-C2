Before you report

Reporting is a signal to moderators, not a way to win an argument. Please use it in good faith.

  • If you disagree with an answer, downvote it — don't report it.
  • If the post is simply unclear, leave a comment asking for clarification.
  • If it's a duplicate, link to the original in the details field.
  • If someone is in immediate danger, contact local authorities first.
What happens next
  1. Your report goes into a moderator queue.

  3. Action is taken if the post breaks the guidelines — edit, lock, or delete.
  4. You're notified of the outcome in your inbox.
